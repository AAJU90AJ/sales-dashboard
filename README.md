# Sales Dashboard

Analysis of sales data using Pandas and Matplotlib.

## Findings
- Total revenue: ₹2.29 crore (₹22,944,200)
- Top product: Laptop, contributing about 61% of total revenue
- Laptop, Phone and Monitor together make up about 95% of revenue
- Best month: February (₹25.0 lakh); weakest month: April (₹13.6 lakh)
- Insight: High-priced products drive revenue, while low-priced items like Mouse and Keyboard contribute very little.
- Note: Sample data used for this project.
